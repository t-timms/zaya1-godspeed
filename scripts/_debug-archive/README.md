# scripts/_debug-archive

Working scratch from the NVFP4 W4A4 bring-up on SM120 — one-off diagnostics,
iterative kernel/loader patch attempts, dequant round-trip probes, and superseded
fix variants. Kept for provenance: `RESEARCH.md` walks the full debugging chain and
some of its steps point here.

Nothing in this directory is part of the reproduction path. The scripts that are —
calibration, quantization, global-scale repair, verification, smoke tests,
benchmarks, the budget-forced eval suite, and serving — live one level up in
`scripts/`. See the **Repo map** and **Reproduce** sections of the top-level README.
